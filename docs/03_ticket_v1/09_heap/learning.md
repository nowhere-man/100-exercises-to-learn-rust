# Heap：堆分配与 `String` 的大小

[对应源码](../../../exercises/03_ticket_v1/09_heap/src/lib.rs)

## 堆与栈

堆用于存放需要动态分配的数据，例如运行时长度才确定的字符串缓冲区。分配器负责找到可用内存并记录分配；拥有该资源的值在释放时负责归还它。堆分配需要分配器管理，通常比只调整栈帧开销更大，但应根据实际需求选择存储方式。

## `String` 的栈上部分

`String` 的文本字节缓冲区在堆上；`String` 值本身则保存管理缓冲区所需的信息。常见实现概念上包含指针、长度和容量，各占一个机器字。64 位目标上它们各为 8 字节，所以此练习中的 `size_of::<String>()` 为 24，三个 `String` 字段的 `Ticket` 为 72 字节。

其中指针指向 `u8` 字节缓冲区：`u8` 是每个元素的类型、占 1 字节；指针本身在 64 位目标上占 8 字节。指针不是 `usize`，只是二者在该目标上的宽度相同。具体布局属于实现细节，不应当作所有平台上的语言保证。

`usize` 是与目标平台指针宽度相对应的无符号整数类型，长度和容量用它表示。字符串长度是 UTF-8 字节数，不一定等于字符数。

## `size_of` 不统计堆缓冲区

`size_of` 只测量类型值本身的大小，不会跟踪运行时分配的堆内存。对 `String` 可以通过 `capacity()` 查询缓冲区容量，但没有适用于任意类型的通用 API 来统计其所有堆分配。
