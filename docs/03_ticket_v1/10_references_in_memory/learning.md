## 引用与指针宽度

普通引用 `&T` 或 `&mut T` 在常见 64 位目标上占 8 字节，不随被引用类型 `T` 的大小改变；本练习分别检查了 `&u16`、`&mut u64` 和 `&Ticket`。可用 `std::mem::size_of` 查看当前目标上的大小。

引用指向一个有效值，但该值不一定在堆上。比如引用可以指向栈上的局部变量，也可以指向堆分配中的数据。因此 `&String` 是指向 `String` 值的引用；而 `String` 自己管理的缓冲区另在堆上。

此处讨论的是普通、已知大小类型的引用；含动态大小类型的引用可能还携带额外的长度等元数据。
