# Outro：实现一个有不变条件的公开类型

[对应源码](../../../exercises/03_ticket_v1/12_outro/src/lib.rs)

## 封装与公开 API

`Order` 的字段保持私有，外部通过公开关联函数 `new` 创建实例，并通过公开 getter、setter 读写字段。集成测试位于独立的 `tests` 目录，只能使用 crate 对外公开的 API，因此类型及测试调用的方法都必须是 `pub`。

`new` 是常见的创建实例的关联函数名，不是 Rust 的特殊关键字或内建构造函数。字段私有时，外部不能用结构体字面量绕过构造时的校验。

## 在构造和修改时维护不变条件

产品名必须非空且不超过 300 字节；数量与单价必须大于零。构造函数和对应 setter 都要执行相同校验，确保对象创建后不能通过 setter 进入非法状态。`String::len()` 计算 UTF-8 字节数，因此 300 的限制是字节限制，不一定是 300 个 Unicode 字符。

## 总价与整数溢出

`quantity` 和 `unit_price` 是 `i32`，直接相乘会先按 `i32` 运算，可能溢出。若 `total` 返回 `i64`，应在乘法之前把两个操作数转为 `i64`：

```rust
i64::from(self.quantity) * i64::from(self.unit_price)
```

本练习校验两者均为正数，两个最大正 `i32` 的乘积仍能放进 `i64`。`total` 只需返回计算结果；输出日志不是题目要求的一部分。
