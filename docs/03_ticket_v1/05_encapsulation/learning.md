# Encapsulation：私有字段与不变量

[对应源码](../../../exercises/03_ticket_v1/05_encapsulation/src/lib.rs)

## 封装保护数据规则

封装是隐藏内部表示，并通过受控接口操作对象。不变量是对象在正常使用期间必须始终满足的规则，例如标题非空、长度合规、状态只能取指定值。

**字段公开时，外部代码可以直接写入类型允许的值，绕过构造方法的验证。** 保持字段私有，再让公开方法维护规则，才能保护这些不变量。

## 私有字段限制外部构造

私有字段会阻止定义模块及其所有层级子模块之外的代码使用 `Ticket { ... }` 构造对象。定义模块内部仍然可以使用这套语法，因此“字段私有就完全不能直接构造”是不准确的。

本题的外部调用者通过 `Ticket::new` 创建对象，验证集中在这一个入口。后续若提供修改方法，也必须维护同样的规则。

## 访问器控制读取接口

访问器（getter）是提供字段读取能力的方法，不要求把字段本身公开。

本题使用 `pub fn title(self) -> String`：调用时拿走整个 `Ticket`，返回标题字符串。它能够通过每次只读一个字段的测试，但不是反复读取同一对象的接口；下一道所有权练习会把接收者和返回值改成引用。
