## 引用与生命周期：`&'static str`

**引用用于借用数据，不取得数据的所有权。** 在返回类型中，`&'static str` 可拆成：

| 部分 | 含义 |
| --- | --- |
| `&` | 共享引用，不能通过它直接修改被引用的数据 |
| `'static` | 生命周期标注，表示被引用的数据在整个程序运行期间有效 |
| `str` | 字符串切片类型，表示一段 UTF-8 文本 |

`'` 是生命周期名称的前缀。字符串字面量 `"hello"` 的类型是 `&'static str`：内容存放在程序的静态存储区域，函数结束后仍然有效。

**生命周期和可变性是两个维度**：

- `&T`：共享借用；`&mut T`：独占的可变借用。
- `'static` 说明数据的有效期，不表示可变或不可变，也不要求引用变量一直存在。
- `&T` 不会让数据永久不可变；它限制通过该引用进行修改。

对比 C++：`&T` 的访问方式可类比 `const T&`，但 Rust 还在编译期检查生命周期与借用关系，防止悬垂引用及冲突访问。

## 表达式、分号与返回值

**表达式会产生值；函数体末尾不带分号的表达式，就是隐式返回值。**

```rust
fn greeting() -> &'static str {
    "hello"
}
```

等价于显式写 `return "hello";`。

在这里加上分号，字符串表达式的值会被丢弃：

```rust
fn greeting() -> &'static str {
    "hello"; // 编译错误：函数要求返回字符串引用，但函数体结果为 ()
}
```

**不是字符串被转换成了 `()`，而是函数体没有尾表达式，结果为 `()`。** `()` 称为单元类型，其唯一的值也写作 `()`，可理解为“没有有用的返回值”。

对比 C++：C++ 通常用 `return` 明确返回；Rust 允许代码块本身产生值，因此能直接用尾表达式表示结果。`return` 仍可用于提前返回。

## 模块、作用域与路径

**模块（`mod`）用于组织代码和控制可见性；同一文件可以有多个模块，各有自己的作用域。**

本练习中，`greeting` 位于根模块，`mod tests` 是子模块。父模块的函数名不会自动进入子模块的作用域。

| 写法 | 含义 |
| --- | --- |
| `crate` | 当前编译单元；本练习的库 crate 以 `src/lib.rs` 为根 |
| `crate::greeting` | 从当前 crate 的根模块定位函数 |
| `super::greeting` | 从当前模块的父模块定位函数 |
| `use crate::greeting;` | 引入这个名字，之后可直接写 `greeting()` |

这里父模块就是根模块，因此 `use super::greeting;` 也可以。还可以省略 `use`，直接调用 `super::greeting()`。

**作用域与访问权限不同**：子模块可以访问父模块的私有函数，所以这里不需要给 `greeting` 加 `pub`（公开可见性标记），但仍需引入名字或写出路径。

对比 C++：嵌套命名空间中的非限定名字可以向外层查找；Rust 对这里的父模块函数要求显式路径或引入，使依赖来源更清楚。`use` 只是名字引入，不会加载或复制函数。

## 内置单元测试

**Rust 的基础单元测试由编译器、标准库和 Cargo 配合提供，无需第三方测试框架。**

```rust
#[cfg(test)]
mod tests {
    use crate::greeting;

    #[test]
    fn test_welcome() {
        assert_eq!(greeting(), "I'm ready to learn Rust!");
    }
}
```

| 语法 | 作用 |
| --- | --- |
| `#[...]` | 属性：附加在代码上的编译指令或元数据 |
| `#[cfg(test)]` | 条件编译：下面的模块只在测试编译时包含，普通构建时排除 |
| `#[test]` | 把函数标记为测试用例，由测试运行器调用 |
| `assert_eq!(a, b)` | 标准库断言宏，默认可用；检查两者相等，不相等则触发 `panic`，使该测试失败 |

`tests` 只是模块名的惯例；**真正识别测试的是 `#[test]`**。调用末尾的 `!` 表示宏调用。

`cargo test` 会编译代码，生成带测试入口的可执行程序，再调用测试函数，因此无需自己写 `main()`。

对比 C++：C++ 通常引入 GoogleTest 等框架；Rust 将基础测试整合进标准工具链，统一常见开发流程。
