# Syntax：整数类型、字面量与类型转换

[对应源码](../../../exercises/01_intro/01_syntax/src/lib.rs)

## 整数类型与取值范围

**整数类型名由符号属性和位宽组成**：`u` 表示无符号，`i` 表示有符号，数字表示占用的位数。

固定宽度整数提供 `8`、`16`、`32`、`64`、`128` 位。对 n 位整数：

| 类型 | 取值范围 | 32 位示例 |
| --- | --- | --- |
| 无符号 `uN` | 0 到 2ⁿ − 1 | `u32`：0 到 4,294,967,295 |
| 有符号 `iN` | −2ⁿ⁻¹ 到 2ⁿ⁻¹ − 1 | `i32`：−2,147,483,648 到 2,147,483,647 |

类型的边界值可通过关联常量访问，例如 `u32::MAX`、`i32::MIN` 和 `i32::MAX`。

## 整数字面量与类型推断

**字面量是直接写在代码中的值**，例如 `2`。没有后缀时，编译器会根据上下文推断整数类型；缺少类型约束时，默认使用 `i32`。

```rust
let a = 2;           // 无其他约束时，推断为 i32
let b: u32 = 2;      // 由变量类型确定为 u32
let c = 2u64;        // 后缀显式指定为 u64
let d = 1_000_000;   // 下划线只改善可读性，不改变值
```

**类型推断不等于类型转换**：`let b: u32 = 2` 是直接把字面量确定为 `u32`，并非先创建 `i32` 再转成 `u32`。

## 运算类型与显式转换

本练习的函数签名：

```rust
fn compute(a: u32, b: u32) -> u32 {
    a + b * 2
}
```

`a`、`b` 和返回值都是 `u32`，运算中的字面量 `2` 也由上下文确定为 `u32`。

**不同整数类型之间不会自动转换，即使转换不会丢失数据。** 已经确定类型的变量需要显式转换：

```rust
let small: u32 = 2;
let large: u64 = u64::from(small); // 显式、无损地转换
```

对比 C++：C++ 的整数运算常会发生隐式提升或转换；Rust 要求明确转换意图，减少位宽和符号变化带来的意外。编译器可以帮你推断类型，但不会替你决定如何转换已有的整数值。
