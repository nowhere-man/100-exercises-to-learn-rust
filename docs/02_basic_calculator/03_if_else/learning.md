# If / else：条件、表达式与提前返回

[对应源码](../../../exercises/02_basic_calculator/03_if_else/src/lib.rs)

## 条件必须是布尔值

**Rust 的 `if` 条件必须是 `bool`，整数不会自动转换成布尔值。** 判断偶数要写 `n % 2 == 0`，不能直接写 `if n % 2`。

C/C++ 允许在条件中把零解释为假、非零解释为真；Rust 要求显式比较，让条件的含义清晰，并在编译时发现类型误用。

## `if` 可以产生值

Rust 的 `if` 是表达式，正常结束的各条路径必须产生兼容的类型。块末尾不带分号的表达式提供这个块的值；函数体末尾的表达式提供函数返回值。

```rust
let result = if n % 2 == 0 { 12 } else { 17 };
```

这里两个分支都产生整数。内部块的值不会自动让整个函数提前返回。

## 没有 `else` 时的单元类型

`()` 叫单元类型，只有一个值，也写作 `()`，表示没有有意义的结果。它的用途类似 C/C++ 的 `void`，但它是真正有值的类型。

**没有 `else` 的 `if`，条件为假时产生 `()`，因此正常结束的真分支也必须产生 `()`。**

```rust
if n % 2 == 0 {
    12; // 丢弃整数值；这个块正常结束，结果为 ()
}
```

去掉 `12` 后面的分号，真分支会产生整数，与假分支的 `()` 不匹配，导致编译错误。

## `return` 与丢弃值不同

`12;` 计算并丢弃值，随后继续执行；**`return 12;` 立即退出整个函数，把 `12` 返回给调用者。**

`return 12` 的类型是 `!`（never type，永不类型），表示表达式不会正常完成。它可以适配要求 `()` 的位置，因为这条路径不会产生一个继续参与后续运算的值。因此，没有 `else` 的 `if` 中可以写 `return 12;`。

当前实现先检查偶数并提前返回，再用函数末尾的 `if / else` 返回 `13` 或 `17`。输入 `6` 时偶数分支优先，返回 `12`。
