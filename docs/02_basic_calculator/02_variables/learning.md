# Variables：声明、类型推断与初始化

[对应源码](../../../exercises/02_basic_calculator/02_variables/src/lib.rs)

## 变量声明与类型

**Rust 的每个变量都有确定的类型，局部变量的类型可以显式指定，也可以由编译器推断。**

```rust
let distance: u32 = end - start; // 显式指定类型
// 也可以写成：let distance = end - start;
```

声明形式为 `let 变量名: 类型 = 表达式;`。本练习中，`end` 和 `start` 都是 `u32`，因此省略类型标注时，`distance` 也能被推断为 `u32`。

## 类型推断会结合后续使用

**没有类型约束时，整数字面量才默认使用 `i32`；不能只看声明那一行判断类型。**

```rust
let x = 42;     // 未指定类型，42 也没有类型后缀
let y = x;      // 要求 y 与 x 类型相同
let z: u16 = x; // 要求 x 为 u16，因此 x、y、z 最终都是 u16
```

**类型推断不是逐行固定类型：`let x = 42` 不会立刻把 `x` 定为 `i32`，编译器还会结合后续约束。** 这里是直接确定 `x` 为 `u16`，没有发生整数类型转换。

如果 `x` 已明确为 `u32`，你的类型不匹配判断就成立：

```rust
let x: u32 = 42; // 也可以写 let x = 42u32;
let z: u16 = x;  // 编译错误：u32 不能隐式转换为 u16
```

函数参数同样如此：`fn example(x: u32)` 已确定 `x` 的类型，函数体中的 `let z: u16 = x;` 不能把它重新推断为 `u16`。

**区分两个过程：类型推断是在确定类型；类型转换是在已有类型之间转换值。** 后续使用可以约束尚待推断的类型，但不能改变已确定的类型。

对比 C++：`auto x = 42` 根据初始化表达式确定为 `int`；Rust 的局部类型推断能结合后续使用。Rust 允许省略可推断的类型标注，同时要求已有整数类型之间的转换显式表达。

## 函数参数需要类型标注

**普通函数定义的参数类型必须显式写出，不能像局部变量一样省略。**

```rust
fn speed(start: u32, end: u32, time_elapsed: u32) -> u32
```

参数是函数调用时由实参初始化的变量绑定；这里的类型构成函数对外的接口。Rust 要求接口明确，让调用者和编译器无需依赖函数体猜测参数类型。

## 声明与初始化可以分开

**可以先声明变量，但读取它之前，编译器必须能确认它已初始化。**

```rust
let distance: u32;       // 声明，尚未初始化
distance = end - start;  // 首次赋值完成初始化
let speed = distance / time_elapsed;
```

首次初始化不要求 `mut`（允许后续修改的标记）；初始化后再重新赋值才需要。

对比 C++：C++ 允许声明未初始化的局部整数，但读取其值会出问题；Rust 在编译期拒绝未初始化的读取，把这类错误提前暴露。
