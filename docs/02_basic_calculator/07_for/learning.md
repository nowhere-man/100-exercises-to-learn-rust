# For：范围、迭代与整数类型推断

[对应源码](../../../exercises/02_basic_calculator/07_for/src/lib.rs)

## `for` 逐个取得元素

迭代器是能依次提供元素的对象。`for element in values { ... }` 会把 `values` 转成迭代器，每次把一个元素绑定给 `element`，直到没有下一个元素。

整数范围可以用于生成连续数字，例如 `for i in 1..=5 { ... }`。

## 范围是否包含终点

| 写法 | 表示的范围 | 能否直接用于整数 `for` |
|---|---|---|
| `1..5` | 从 1 到 4，不包含 5 | 能 |
| `1..=5` | 从 1 到 5，包含 5 | 能 |
| `1..` | 从 1 开始，没有指定终点 | 能，但要注意终止与溢出 |
| `..5` | 所有小于 5 的值 | 不能 |
| `..=5` | 所有小于或等于 5 的值 | 不能 |

这是注释讨论的五种写法，并非 Rust 所有范围形式的完整列表。

**描述范围包含哪些值，不等于可以逐个迭代它们。** 整数类型确定后，`..5` 包含从该类型最小值到 4 的值，但它不提供迭代起点，不能直接用于 `for`。它可用于切片，例如 `&array[..5]`。

`1..` 不会在整数最大值处自动结束；迭代到类型边界时会涉及溢出。需要有限循环时，应指定终点或及时 `break`，不能把它当成“安全地遍历到最大值”的范围。

## 循环变量的类型来自范围

**`i` 的类型由范围端点决定，端点再由上下文推断；没有其他约束时，整数默认是 `i32`。**

```rust
for i in 0u32..5 {
    // i 和终点 5 都是 u32
}
```

`0u32` 中的 `u32` 是类型后缀；改成 `0i32` 即可明确指定 `i32`。这不是隐式类型转换，而是编译时确定类型。与 C++ 的 `for (int i = ...)` 不同，Rust 从被迭代的元素类型推断循环变量。
